# HSK Contract Watchdog

One-page pitch, editable in the browser.

- `/` — edit mode (click any text, edits persist in localStorage)
- `/?mode=preview` — clean public view, tools hidden
- `/?mode=tv` — 16:9 presentation mode (arrows/space, `F` fullscreen, `Esc` exit)

"Export HTML" (or Cmd+S) downloads an index.html with your edits baked in — commit it to publish.
